# 🌸 Sakura壁纸

一个基于纯原生 HTML / CSS / JavaScript 构建的高清壁纸展示与下载 Demo，界面风格参考 [haowallpaper.com](https://haowallpaper.com)。

## ✨ 功能特性

- 🖼️ **壁纸画廊** — 16 张精选高清壁纸，4 列响应式网格展示
- 🎠 **Hero 轮播** — 首屏自动轮播（5 秒切换），支持指示器手动切换
- 🔍 **关键词搜索** — 实时过滤（大小写不敏感）
- 🏷️ **多维筛选** — 按类别（电脑/手机/动漫/风景）和标签筛选，支持按名称排序
- 🔆 **明暗主题** — 亮色/暗色模式切换，偏好自动保存至 localStorage
- 🖱️ **灯箱预览** — 点击放大，支持上/下键及屏幕按钮翻图，按 `Esc` 关闭
- 💤 **懒加载** — 图片延迟加载，提升首屏性能
- 📱 **响应式布局** — 适配桌面与移动端

## 🛠️ 技术栈

| 类别 | 技术 |
|------|------|
| 结构 | HTML5 |
| 样式 | CSS3（自定义属性、Flexbox、Grid、毛玻璃效果） |
| 逻辑 | Vanilla JavaScript（ES6+） |
| 服务 | `npx serve`（本地静态文件服务） |

## 🚀 快速开始

**前置要求**：已安装 [Node.js](https://nodejs.org/)（任意 LTS 版本均可）

```bash
# 克隆仓库
git clone https://github.com/ruihao-yan/web-wallpaper.git
cd web-wallpaper

# 启动本地服务器
npm start
```

浏览器访问 [http://localhost:3000](http://localhost:3000) 即可预览。

### 可用命令

| 命令 | 说明 |
|------|------|
| `npm start` / `npm run dev` | 启动本地预览服务器（3000 端口） |
| `make dev` | 同上（通过 Makefile） |
| `make install` | 检查 Node.js 环境 |
| `make update` | 清理/更新 npx 缓存 |
